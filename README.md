# 📚 Student System (Студенттер тізімі жүйесі)

## 📌 Жоба туралы
Бұл жоба студенттердің мәліметтерін басқаруға арналған шағын Python бағдарламасы. Бағдарлама студент қосу, іздеу, сұрыптау және файлға сақтау функцияларын орындайды.

---

## 🎯 Жобаның мақсаты
Студенттердің мәліметтерін тиімді басқаруға арналған қарапайым ақпараттық жүйе құру.

---

## ⚙️ Қолданылатын функциялар

- ➕ Студент қосу  
- 📋 Студенттер тізімін көрсету  
- 🔍 Студент іздеу  
- 🔃 Студенттерді сұрыптау  
- 💾 Мәліметтерді файлға сақтау  

---

## 🧠 Бағдарлама мүмкіндіктері

- Python тілінде жазылған  
- Модульдік құрылым қолданылған  
- Тізім (list) арқылы деректер сақталады  
- Файлға жазу мүмкіндігі бар  
- Қарапайым консольдік интерфейс  

---
